WELCOME TO FLUXWEAVE

Connect ideas.
Make them move.

A native WebGPU visual-programming environment. Every preview is the result of your network, evaluated live.

Build a network

Press Tab to add an operator. Drag an output port on the right to a matching input on the left. Purple carries textures; green carries signals; blue carries geometry.

Shape the result

Select a node to edit parameters. Double-click to view it. Use the diamond beside a parameter to keyframe it; the link control binds a numeric channel.

Move through ideas

Drag the background to pan. Scroll to zoom. Shift-drag to select a region. H frames the network. Space plays or pauses.

Make it reusable

Select a network with one outgoing operator and press ⌘ G. The component appears in your library. Double-click it to edit its shared definition.

Camera and microphone access is always explicit. Projects and embedded media are stored locally in IndexedDB. .flux files include your graph, shaders, keyframes, components, and imported assets. This is an independent product, not a Derivative product or a .toe-compatible application.
